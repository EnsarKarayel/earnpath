# Ürün Gereksinimleri

## Ana Vaat

Kullanıcıya "benim durumumda para kazanmaya en hızlı nasıl başlarım?" sorusunun uygulanabilir cevabını vermek.

## Kullanıcı Tipleri

- Acil iş arayan
- Öğrenci
- Evden çalışmak isteyen
- Diplomasız iş arayan
- Dil bilen ama yol bilmeyen kişi
- Kariyer değiştirmek isteyen
- İşveren veya küçük işletme

## Ana Akış

1. Kullanıcı dilini seçer.
2. Profil bilgilerini girer.
3. Sistem 3 rota önerir.
4. Kullanıcı bir rotayı seçer.
5. 30 günlük görev planı oluşur.
6. CV özeti ve başvuru mesajı hazırlanır.
7. Kullanıcı başvurularını takip eder.
8. Gerekirse ücretli pakete geçer.

## Web Ekranları

- Onboarding
- Profil
- Rota sonucu
- Plan takibi
- CV ve başvuru mesajı
- Ödeme
- Hesap
- Admin

## Mobil Ekranlar

- Dil seçimi
- Giriş/kayıt
- Hızlı profil
- Bugünün görevi
- Rota sonucu
- Başvuru takip
- Bildirimler
- Profil ayarları

## Admin Ekranları

- Rotalar
- Beceri etiketleri
- Kurslar
- Şehir destekleri
- Dil çevirileri
- Kullanıcı raporları
- Ödeme ve paketler

## İlk Ücretli Paketler

- CV + başvuru paketi
- 30 gün takip paketi
- İşveren aday yönlendirme paketi
