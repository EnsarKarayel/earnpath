# EarnPath Product Map

## Positioning

EarnPath is not a generic job board. It is a decision and execution layer for people who need to start earning as quickly as possible.

## First Customer

- Young adults looking for their first or next job
- People with limited formal education
- People who only have a phone
- Migrants and multilingual candidates
- Students who need part-time income
- Career changers who need a concrete first step

## MVP

1. Profile intake
2. Ranked income routes
3. 30-day plan
4. Resume summary
5. Application message
6. Application tracker
7. Paid resume/application package
8. Mobile daily task flow

## Revenue Model

- Free route analysis
- Resume and application pack
- 30-day guided follow-up
- Course referral revenue
- Employer candidate referral packages

## First 14 Days After Launch

- Day 1-2: Publish web MVP
- Day 3-5: Test with 20 real users
- Day 6-7: Sell the resume/application pack manually
- Day 8-10: Publish short-form content with route examples
- Day 11-14: Target the first 10 paid customers

## Key Metrics

- Completed profiles
- Saved plans
- Paid package conversion
- Applications sent per user
- Interviews received
- Users who start earning within 30 days

## Next Version

- Real job source integrations
- Payment checkout
- User accounts
- Admin panel
- City-specific course and support database
- iOS and Android release builds
